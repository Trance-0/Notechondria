# Frontend (Flutter)

This Flutter app is the client for the Canvas-like calendar experience.

## Pages in MVP scaffold

- Front Page
- Learner View
- Course View
- Activity View
- Settings View

Each page is reachable from the bottom navigation bar in `lib/main.dart`.

## Run locally

```bash
flutter pub get
flutter run -d chrome
```

## Test

```bash
flutter test
```
