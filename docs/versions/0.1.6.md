# Notechondria

Version: 0.1.6
Build Date: 2026-04-07T07:00

## What's Changed

### Fix `web` package CI build failure

- [x] Replaced `package:web` (v1.1.1, incompatible with CI Dart SDK) with conditional-import URL strategy (`url_strategy.dart` stub + `url_strategy_web.dart` using `dart:html`). Tests now pass in both VM and browser.
- [x] Removed `web: ^1.1.0` from `pubspec.yaml` and `dart:js_interop` import — eliminates the external dependency that caused the build failure.

### Gitignore update

- [x] Added `backend/mediafiles/` to `.gitignore` to prevent generated test media files from being committed.

### Invitation code and email verification (frontend completion)

- [x] Invitation code backend was already implemented (`InvitationCode` model with SHA-256 hash, auto-hash on save, consume on use, required only when codes exist in DB). Marked as complete.
- [x] Email verification backend was already implemented (`VerificationCode` model with SHA-256 hashed 6-digit codes, `ResendVerificationSerializer` with 60s cooldown, SMTP env vars). Marked as complete.
- [x] Added `resendVerification(email)` method to the frontend HTTP client interface and implementation, calling `POST /auth/resend-verification/`.
- [x] Added "Resend code" button with 60-second cooldown timer to the `_EmailCodeDialog` verify dialog. Button is disabled during cooldown and shows remaining seconds.
- [x] Wired `onResendVerification` callback through `_AuthHub` → `_SettingsPage` → `_AppShellState` for the editor app.

### Remove planner front page module

- [x] Deleted `frontend/planner_app/lib/modules/front.dart` and its `part` import.
- [x] Removed `_frontPage` state, `_frontPageFallbackPayload()`, `_refreshFrontPageData()`, and `getFrontPage()` client method.
- [x] Simplified `_chooseDefaultCourse()` — no longer references front page default_course.
- [x] Renumbered navigation indices (Learner=0, Course=1, Activity=2, Settings=3). Updated `_buildPage()`, `_showWidePageHeader`, `_showCompactPageHeader`, and `_hasRenderableLocalState`.
- [x] Removed `front_page` from local cache persistence and default cache template.
