# 0.1.125 - editor deep links, debug log filters, and Inbox migration

## User request

Finish the current `docs/TODO.md` shared-component and editor-app feature
requests and bug fixes.

## What changed

- Collapsed the shared Debug log filter/source selector by default while
  keeping the active severity/source summary visible.
- Added `timed(...)` wrappers to planner and portal bootstrap fetches so
  Debug log entries include `durationMs`, matching the editor bootstrap path.
- Kept editor note links on `#/notes/<uuid>` for opened notes and added a
  private-note prompt for unauthorized deep links instead of silently falling
  back to the app root.
- Moved Apple Journal ZIP import from Local data to Developer settings and
  added start, cancel, parse, target, failure, and completion logs.
- Added a signed-in legacy Inbox migration prompt for owned `Inbox`
  categories. Users can move notes into a new category or remove the old
  category so notes fall into the uncategorized bucket.
- Updated the editor app docs and moved the finished TODO items into this
  round log.

## Verification

- `flutter analyze` was run for `frontend/editor_app`,
