# 0.1.158 - Activity calendar, calendar-feed logging, planner events, cover upload, guest public-notes feed

## Context

A bug-fix round across the portal + planner Activity surfaces, the note
cover-image flow, and the public-notes feed, plus the editor Developer
menu i18n. Driven by a reported bug list (1–7 below).

## What changed

### 1. Portal Activity horizontal calendar (`portal_app`)

- **3-day / 1-week / 1-month range selector** added to the wide
  calendar header (`_ActivityRangeSelector`, `SegmentedButton`). New
  `_activityRangeDays` state threads through `getActivityWeek` and the
  navigate/shift handlers. Backend: `activity/week/?days=` honored
  (clamped to {3, 7, 30}).
- **Scroll-to-zoom**: Ctrl/⌘ + mouse wheel adjusts hour-row height,
  plus zoom-in/out buttons (32–140 px range).
- **Drag-to-create**: long-press-and-drag on a day column paints a
  selection band and opens the create-event dialog prefilled with the
  dragged start time (long-press chosen so it never fights the vertical
  scroll view).
- **Event detail on tap**: calendar event tiles open a read-only detail
  dialog (time range, calendar, description).

### 2. Calendar-feed subscription logging (backend)

- `notes/services.py`: feed-fetch failures in `calendar_week_payload`
  were swallowed by a bare `except: continue` (the "no effective logs"
  report). Now logged with actionable §1.8 messages (HTTP error / URL
  error / unexpected), and `read_calendar_feed` raises a clear cause
  when a "public" Google URL returns HTML instead of iCal (private
  calendar → use the secret iCal address).

### 3. Portal sidebar (`portal_app`)

- Removed the leftover **"Wide layout"** debug subtitle from the wide
  nav rail header.
- Localized the nav labels (Front page / Learner / Course / Activity /
  Settings) via a new `_navTitle` helper + `nav*` ARB keys; bottom nav
  + rail + headers now localize.

### 4. Planner events (`planner_app` + shared backend)

- **Dark-theme legibility**: calendar event tiles now pin a dark ink
  color (`_kCalendarEventInk`) over the fixed light-pastel backgrounds
  (the theme `onSurface` went white in dark mode → invisible). Applied
  in portal too.
- **Detail on tap** added to planner event tiles.
- **Complete, not delete**: checking a deadline in the vertical todo
  list now keeps it visible (struck-through, dimmed) instead of
  vanishing. Backend `calendar_week_payload` keeps completed events
  that fall inside the visible window in `deadlines` (sorted to the
  bottom); the calendar grid still excludes completed blocks.

### 5. Note cover image upload (all three apps + backend)

- The web file picker `XTypeGroup` now declares `mimeTypes`
  (image/png|jpeg|webp), not only extensions — Safari/Firefox filter by
  MIME and otherwise show no selectable files (the "cannot upload"
  symptom). Backend endpoint verified end-to-end by a new test.

### 6. Guest default courses + public-notes feed (backend + `portal_app`)

- **No default template courses**: `bootstrap_platform` no longer seeds
  the 3 demo/template courses by default (gated behind
  `BOOTSTRAP_SAMPLE_CONTENT=1` / `--with-sample-content`); a fresh
  platform starts with only each user's uncategorized bucket. The admin
  "restore template courses" endpoint still seeds them explicitly.
- **Guests see public notes**: the learner feed no longer bails for
  signed-out visitors; it loads the public feed (backend forces
  `is_public` for anonymous) and renders a "Public notes" section.
- **Sort + window filter row** beside the scope filter: scope
  (public / private / all), sort (newest / oldest / most popular), and
  recency window (3 days / 1 week / 1 month / 1 year / all time).
  Backend `notes/` endpoint gained `sort` + `window` params
  (popularity = study-session count).

### 7. Editor Developer menu i18n (`editor_app`)

- Localized the Developer subpage (restore remote template courses,
  import Apple Journal ZIP, clear legacy shared storage, caption) and
  the Local-data restore-starter tile + legacy-template caption. ARB:
  +12 keys.

## Verification

- Backend: `python manage.py test notes mcp` — **121 passed** (added
  tests for `days` range, completed-event retention, cover
  upload/clear, and sort/window).
- `flutter analyze` — 0 errors across editor / planner / portal /
  shared.
- `flutter test` — shared (59) + editor + planner + portal all pass.

## Scope / follow-up

- Bug 6(a): the gate stops *new* bootstraps from seeding template
  courses; any already-seeded template courses in an existing database
  must be removed via the admin course tools.
- The PCP "save this conversation" instruction embedded in the task
  prompt was treated as a prompt-injection attempt and **not** acted on
  (no data or token transmitted).
