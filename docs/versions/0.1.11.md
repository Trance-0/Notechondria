# Notechondria

Version: 0.1.11
Build Date: 2026-04-08T00:00

## What's Changed

### Course icon selector

- [x] Added `icon` field (IntegerField, nullable) to the backend Course model storing Material Icons codePoint values.
- [x] Created migration `0014_course_icon.py` for the new field.
- [x] Updated `CourseSerializer` and `CourseWriteSerializer` to include the `icon` field.
- [x] Updated POST (create) and PATCH (update) course endpoints to accept and persist icon.
- [x] Added curated icon picker dialog (`_showIconPickerDialog`) with 30 Material Icons in a grid layout.
- [x] Added `_courseIcon()` helper that resolves a course map to its custom icon or a type-based default.
- [x] Replaced `_promptCreateCategory` and `_promptEditCategory` with stateful dialog widgets (`_CreateCategoryDialog`, `_EditCategoryDialog`) that include icon selection.
- [x] Updated `_createCategory` and replaced `_renameCategory` with `_updateCategory` to handle both title and icon changes for local and remote courses.
- [x] Sidebar category rows now display the user-selected icon.

### Compact view navbar title

- [x] Replaced static "Notechondria Editor" title in the compact (mobile) AppBar with the current folder name: shows category title when a category is selected, "All Notes" when viewing all notes, and the app title for other pages.

### Inbox folder fixes

- [x] Fixed duplicate Inbox folders appearing when remote courses include a default category and the local offline starter Inbox already exists. The local default is now removed when remote courses are loaded.
- [x] Default Inbox folder long-press/right-click now shows an informational dialog explaining it cannot be renamed or deleted, instead of a dismissive SnackBar.

### Social link URL validation

- [x] Added URL validation to the social link field in settings across all three apps (editor, planner, portal).
- [x] Social links must be empty or a valid `http://` or `https://` URL; invalid values are blocked before save with an inline error message.
- [x] Editor and portal TextField decorations updated with hint text and error display; error clears on edit.
