# 0.1.168 - Build fix: thread onEventLongPress through _MonthDayCell

## Context

0.1.167 added hold-to-edit but its Flutter build failed: the month-grid
event chips live in a separate `_MonthDayCell` widget, and the new
`onEventLongPress` callback was added to `_MonthCalendarGrid` but not
threaded into `_MonthDayCell`, so `onEventLongPress` was undefined where
the chips are actually built. (The local brace/JSON checks can't catch
an undefined-name error; only the CI Flutter build does — which is why
this is a fast follow-up.)

## What changed

`_MonthDayCell` gained the `onEventLongPress` field, and
`_MonthCalendarGrid` now passes it down at construction. No behaviour
change beyond making 0.1.167's hold-to-edit compile and reach the month
grid.

## Verification

- The two CI errors were the only errors in the 0.1.167 build log
  (`onEventLongPress` undefined for `_MonthDayCell`, ×2 for the app +
  smoke-test recompile); both are resolved.
- Interpolation-aware Dart brace balance passes. Flutter build not run
  locally — `frontend-pages.yml` is the authority post-push.
