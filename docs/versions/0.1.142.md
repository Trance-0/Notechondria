# 0.1.142 - Share-link deep-link fix + i18n Phase 1d (note viewer/editor menus)

## User request

Two things: (1) the share URL still doesn't work —
`https://trance-0.github.io/Notechondria/editor/#/notes/<uuid>` lands on
the editor home instead of the note preview; (2) continue translation,
including the sub-menus.

## Share-link deep-link fix

**Symptom:** a cold-opened share link drops you on the editor home with
no note dialog (and not even the private-note prompt) — meaning the
fragment was parsed as null.

**Root cause:** the editor uses Flutter's **default hash URL strategy**
(no `usePathUrlStrategy()`), and the app is a `MaterialApp(home:)` with
no `/notes/<uuid>` route table. On the first frame Flutter's router
normalizes the unmatched initial route and rewrites the hash from
`#/notes/<uuid>` back to `#/`. The deep-link read
(`_parseNoteUuidFromUrl` → `Uri.base.fragment`) runs in `_bootstrapApp`
only **after** `await _loadInitialData()` (several seconds), by which
point the fragment is already gone. The well-tested
`parseNoteUuidFromFragment` regex was never the problem — the fragment
was empty by the time it was called.

**Fix:** snapshot the launch fragment in `main()` into the top-level
`bootInitialFragment` **before** `runApp()`, while the URL is still
pristine. `_parseNoteUuidFromUrl()` now reads that snapshot first and
only falls back to the (possibly-clobbered) live `Uri.base`. After the
note opens, `_replaceNoteUrl(uuid)` restores `#/notes/<uuid>` in the
address bar as before.

**Regression test:** `editor_app/test/deep_link_open_test.dart` — the
flutter_test environment has an empty `Uri.base.fragment` (exactly the
clobbered production state), so the test only passes if the boot
snapshot drives the deep link. It seeds `bootInitialFragment =
'/notes/<uuid>'`, boots with a fake client, and asserts the note viewer
opens on the shared note. The existing `deep_link_parser_test.dart`
still covers the pure regex.

## i18n Phase 1d — note viewer/editor sub-menus (en + zh)

- **Note viewer** (`components/note_viewer.dart`) — the share-link
  preview page itself: Back, Untitled note, Options, and the options
  menu (Edit / Copy link / Export markdown / Delete) + the
  "Link copied" snackbar.
- **Note editor** (`modules/note_editor.dart`) — the "More actions"
  menu (Edit note meta, Switch editor: Plain text / Live markdown, View
  attachments), the Copy-link button + snackbar, and the Title / "Write
  your note…" / Attach-file hints.
- **Private-note / load-error dialogs** (`core/auth_flows.dart`) — the
  "Private note" prompt (title, body with the deep-link, Close, Open
  settings) and the private/load error messages.
- ARB: +~20 keys (`note*`, `privateNote*`, plus the `{link}` / `{reason}`
  placeholders). Regenerated `AppLocalizations`.
