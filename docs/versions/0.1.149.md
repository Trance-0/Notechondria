# 0.1.149 - i18n fixes: clear-all-data button + onboarding tour content

## User reports

1. **Bug:** in editor Settings, the "Clear all local data" button (and
   its confirm dialog) was not translated.
2. **Bug:** the tutorial (onboarding tour) did not respond to the
   Language setting — switching to 简体中文 left the tour in English.

## Root cause (tour)

0.1.147 localized the onboarding-tour **chrome**
(Close/Skip/Back/Next/Done), but each app's tour **step content**
(title + body) was a `const _kOnboardingSteps` list of hardcoded English
`TourStep`s, passed into `showOnboardingTour`. Const data can't read
`AppLocalizations`, so the steps never changed with the locale.

## What changed (en + zh)

- **Editor "Clear all local data"** (`editor_app/lib/modules/settings.dart`):
  the danger-zone tile (title + subtitle) and the `ConfirmWithDelayDialog`
  (title, message, confirm label) now read from `AppLocalizations`.
- **Onboarding tour content — all three apps**
  (`{editor,planner,portal}_app/lib/core/onboarding.dart`): replaced the
  `const _kOnboardingSteps` list with an `_onboardingSteps(AppLocalizations
  l10n)` builder, called from `_runOnboarding` with the live
  `AppLocalizations.of(context)`. Now the tour text follows the Language
  setting. Icons + the app-title header (a brand name) are unchanged.
- ARB: +~25 keys (`clearAllLocalData*`, `tourEditor*`, `tourPlanner*`,
  `tourPortal*`), regenerated `AppLocalizations`.

## Verification

- `flutter analyze` — 0 errors across shared + all three apps.
- `flutter test` — shared suite + all three smoke tests pass.
- `flutter build web` — all three apps pass.

## Scope / follow-up

Replaying the tutorial after switching Language now shows translated
steps. (A tour already on screen during a live language switch won't
re-localize until reopened — steps are built when shown; acceptable.)
Still open in `docs/TODO.md`: UI-level warning strings (e.g. "client
failed to fetch"), the version-update notification feature, and
