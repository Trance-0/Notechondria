# 0.1.105 — `migrate_users_to_casdoor`: `--invitation-code` + `--admin-password-from-env`

Two flags on the existing
[`migrate_users_to_casdoor`](../../backend/creators/management/commands/migrate_users_to_casdoor.py)
management command (lives since 0.1.101) so the operator can
actually run the cutover against production with the constraints
they outlined:

* **`--invitation-code <code>`** — when set, every upserted Casdoor
  user gets the value written to its `tag` field. Lets the operator
  filter migrated-vs-self-signup users in the Casdoor admin UI by
  tag value. Notechondria's legacy invitation codes (e.g. the
  `y5cda397qz` minted by the legacy `/auth/invitation/` flow) are
  the expected input.
* **`--admin-password-from-env`** — when the user being upserted
  matches `DJANGO_SUPERUSER_USERNAME` (case-insensitive,
  defaults to `"admin"`), set their Casdoor password to the value
  of `DJANGO_SUPERUSER_PASSWORD` instead of a random string. Lets
  the operator keep the admin's password in lockstep with the
  `.env` file across the migration. Other users still get a random
  password and the Casdoor "Forgot password?" handoff. The flag
  hard-stops with a clear error when `DJANGO_SUPERUSER_PASSWORD`
  is empty in the shell — destructive enough to want a definite
  stop rather than silently giving the admin a random password.

The dry-run output now includes the password origin (`env` vs
`random`) and the tag value so the operator can sanity-check before
firing the real command.

## Operator runbook (post-deploy of this round)

From a Northflank shell on the backend service (Service → Tools →
Shell):

```
# Confirm CASDOOR_* + DJANGO_SUPERUSER_PASSWORD are set in the env.
env | grep -E '^(CASDOOR_|DJANGO_SUPERUSER_)' | sort

# Sanity check against the production DB without touching Casdoor.
python manage.py migrate_users_to_casdoor \
    --dry-run --limit 10 \
    --invitation-code y5cda397qz \
    --admin-password-from-env

# Real run, small batch first.
python manage.py migrate_users_to_casdoor \
    --limit 10 \
    --invitation-code y5cda397qz \
    --admin-password-from-env

# Full batch once you're satisfied.
python manage.py migrate_users_to_casdoor \
    --invitation-code y5cda397qz \
    --admin-password-from-env
```

Idempotent — skips users whose `Creator.casdoor_sub` is already
set (use `--retry-existing` to override).

  its sandbox; the operator must execute it themselves.
