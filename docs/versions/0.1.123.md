## What changed

- Added `CourseSubscription.is_private` plus a migration and serializer
  field (`is_private_subscription`) so the backend can distinguish a
  normal subscription from a private sidebar subscription.
- Completed `POST /api/v1/courses/<id>/subscribe-private/` and added
  backend tests for setting private visibility and for clearing it when
  the user later uses the normal subscribe endpoint.
- Added `NotechondriaClient.subscribePrivateCourse` and a sidebar
  action for foreign cloud categories. The user can now keep a cloud
  category privately without taking ownership or republishing it.
- Added Settings -> Local data -> Import Apple Journal ZIP. The first
  experimental phase is web-safe ZIP import: it parses Markdown/JSON
  entries, lets the user choose an existing local category or create a
  new one, creates local GFM drafts with frontmatter/metadata, queues
  referenced media into `LocalAttachmentStore`, and leaves cloud sync
  paused until a manual push.
- Added tracked `.gitignore` entries for `scripts/db_backup/` and
  `scripts/r2_backup/` because those generated archives may contain
  production database rows and Cloudflare R2 user media.
- Removed the project-local "Never edit `.gitignore`" override from
  `docs/index.md`.

## Docs

Updated the Editor app docs and backend API spec to document private
course subscriptions and the Apple Journal ZIP-first import contract.
