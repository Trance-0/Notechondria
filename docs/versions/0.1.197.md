# 0.1.197 - Note-conflict resolver: side-by-side diff (#31)

Fixes #31. When a keep-offline pull found a local note and a cloud note
sharing a title, the "Resolve note conflict" dialog showed only a
three-line **summary** of each side — not enough to tell what actually
differed. It now shows a **side-by-side, git-diff-style view**: local on
the left, cloud on the right, with changed / added / removed lines
highlighted.

## What ships

- **`diffLines(localText, remoteText)`** — a pure LCS line-diff in the
  shared package (`src/utils/line_diff.dart`) returning aligned
  `DiffRow`s (`equal` / `changed` / `removed` / `added`). A run of
  removed lines immediately followed by added lines is paired into
  `changed` rows so an edit shows old-vs-new on the same row. CRLF/CR is
  normalized so a bare line-ending difference is not a change. Pure and
  dependency-free.
- **`NoteConflictDiffView`** — a shared widget
  (`src/components/note_conflict_diff.dart`) rendering the rows two-up:
  monospace, height-capped with internal scroll, git-diff tints that read
  in light and dark, "Local" / "Cloud" headers, and an "identical"
  message when nothing differs.
- The `_showPullConflictDialog` in **all three apps** (editor / planner /
  portal) now embeds `NoteConflictDiffView` over the note *content*
  (falling back to `_noteToMarkdown` for the remote side) instead of the
  old per-side excerpts. The dialog width is now responsive
  (`clamp(280, 640)`) to fit the two columns; the Keep-local / Use-server
  choice is unchanged.

## Verification

- `portal_app/test/smoke_test.dart` (CI-run) covers `diffLines`:
  identical → all `equal`; a replaced line → one `changed` row with old
  on the left and new on the right; remote-only → `added`, local-only →
  `removed`; CRLF-vs-LF alone → all `equal`; empty-vs-nonempty → all
  `added`. The risky decision (the diff) is a pure function, unit-tested
  in CI; the widget layout is exercised by `flutter build web`.
- Bracket-balanced and reference-checked across the shared package and
  all three dialogs; the shared barrel exports `diffLines` / `DiffRow` /
  `DiffLineKind` / `NoteConflictDiffView`.

Closes #31
