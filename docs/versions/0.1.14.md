# Notechondria

Version: 0.1.14
Build Date: 2026-04-08T00:00

## What's Changed

### Jenkins build fixes

- [x] Fixed `boto3==1.35.0` / `urllib3==2.1.0` dependency conflict by downgrading urllib3 pin to `>=1.25.4,<1.27` (compatible with botocore).
- [x] Added `--no-tree-shake-icons` to `flutter build web` in all three frontend Dockerfiles to fix icon tree-shaking build failures.

### Django admin portal improvements

- [x] Enhanced all admin list views across `creators`, `notes`, and `gptutils` apps with owner names (first + last name), parent object titles, metadata columns, filters, and search fields.
- [x] Registered previously unregistered models: `SocialAccount`, `NoteVersion`, `NoteActivitySession`, `Tag`.
- [x] Added inline views: `NoteVersionInline` on Note admin, `CourseMediaInline` on Course admin.
- [x] Note admin now shows parent note title for comment-type notes.

### Change email and change password

- [x] Added `POST /api/v1/auth/change-password/` endpoint (validates current password, rotates auth token on success).
- [x] Added `POST /api/v1/auth/change-email/` endpoint (two-step: sends 6-digit verification code to new email, then confirms with code).
- [x] Added `changePassword`, `changeEmailRequest`, `changeEmailConfirm` methods to the Flutter API client.
- [x] Replaced single Logout button with a row of `Change email`, `Change password`, and `Logout` buttons in editor settings.
- [x] Created dialog UIs for both change-password and change-email flows with validation and feedback.

### Chrome password manager autofill

- [x] Added `AutofillGroup` with `autofillHints` (`newUsername`, `email`, `newPassword`) to the registration form fields.
- [x] Simplified login field autofill hint to `AutofillHints.username` only (was `[username, email]` which confused Chrome).
- [x] Added 100ms delay between `TextInput.finishAutofillContext()` and dialog close to allow Chrome to capture credentials.

### Splash animation speed

- [x] Slowed Krebs cycle animation from 8s to 12s per cycle across all three apps (~65% of previous speed).

### Environment and deployment

- [x] Populated `sample.jenkins.env` with all required environment variables for Jenkins deployment.
- [x] Added Cloudflare R2 and `FRONTEND_ORIGIN` variables to `prepare_env.sh` for shell-based env generation.
