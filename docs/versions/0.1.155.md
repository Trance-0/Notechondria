# 0.1.155 - Portal i18n: learner feed + note-metadata dialog

## Context

Continuing TODO i18n Phase 3 (portal). 0.1.154 did the front page +
course browser; this round localizes the **notes feed** and the **note
details dialog**.

## What changed (en + zh)

- **`learner.dart`** (portal notes feed): the composer menu (Create
  note / Import markdown), search hints (cloud / local), the
  unsynced-drafts card (header / Sync all / help), the Recent-notes /
  Local-drafts headers + empty states, "Load notes", the FAB tooltips,
  the per-note card (Untitled / Local-draft / Public / Private badges,
  the Edit / Sync-to-cloud / Export / Delete menu, the course-metadata
  hint), and the Load-more / Loading state. Reused the editor's existing
  `feed*` / `common*` / `note*` keys where they matched; added a few
  portal-specific ones.
- **`note_metadata_dialog.dart`**: the cover-image section (title, the
  three state help texts, Replace / Upload / Remove), the dialog
  (Note details, Assigned course / plan, Section, Short description,
  Public note + its two help texts, Version history + empty state,
  Restore, Cancel, Save). Keys are `noteMeta*` so the editor's
  equivalent dialog can share them in a later round.

ARB: +~30 keys (`feed*`, `noteMeta*`, `commonLoading`), regenerated
`AppLocalizations`.
