# 0.1.170 - Course ↔ GitHub binding: backend config endpoints + owner-only exposure

## Context

Owner request: bind a course to a GitHub repo, with the backend as the
source of truth and a lazy commit/sync after N idle minutes (owner-set,
default 5), using the **existing Course model** (0.1.164 added the git
fields — no new model). This round lands the **binding config API** that
the Cloudflare-style repo selector and the sync worker will build on.
The lazy-sync worker, actual GitHub push, repo listing, and template
repo creation remain (tracked in TODO; some need the Nesbitt-bot
credential and a scheduler).

## What changed (backend)

- **`CourseGitBindingApiView`** at `courses/<id>/git/` (owner-only):
  - `GET` returns the binding config.
  - `PUT` binds / re-points / tunes it (`repo` as `owner/name`,
    `branch`, `sync_enabled`, `sync_timeout_minutes` 1–1440). Setting a
    repo arms the lazy-sync debounce (`git_pending_since = now`) and
    clears any stale error; clearing it disables sync.
  - `DELETE` unlinks (clears repo, disables sync, clears pending/error).
  - `CourseGitWriteSerializer` validates the `owner/name` repo shape via
    `GIT_REPO_RE`.
- **Effective logs**: every mutation writes a `CourseOperationLog` row
  (`GIT_BIND` / `GIT_UNLINK`) plus a structured `logger.info`, so the
  owner gets the import/bind/unlink log they asked for. Added
  `GIT_BIND/GIT_UNLINK/GIT_IMPORT/GIT_SYNC` to
  `CourseOperationTypeChoices` (choices only — no migration; the
  `operation_type` column already fits).
- **Owner-only exposure**: `CourseSerializer` gained a `git` field
  (`course_git_payload`) returned only to the course owner — subscribers
  and anonymous viewers get `null`, so a private repo/branch never
  leaks.

## Verification

- `python3 -m py_compile` on every edited backend module.
- Tests (`HeatmapApiTests`): bind → GET/serializer reflect the repo and
  arm `pending_since` + log a `GIT_BIND`; an invalid repo name 400s;
  unlink clears + logs `GIT_UNLINK`; a non-owner PUT 403s and the
  serializer returns `git: null` for another owner's course.
- Django suite not run locally (host budget); `backend-tests.yml` is the
  authority post-push.
