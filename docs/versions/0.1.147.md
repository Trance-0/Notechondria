# 0.1.147 - i18n Phase 4 (part 1): shared-widget chrome localized

## User request

Continue through `docs/TODO.md`. i18n **Phase 4**: localize the
remaining shared widgets used across all three apps.

## What changed (en + zh)

Five shared widgets in `notechondria_shared/lib/src/components/` now
read their chrome from `AppLocalizations`:

- **`storage_usage_card.dart`** (added to planner/portal in 0.1.144, was
  English): title, the Backend / Backend-storage / Local-data-used /
  Browser-storage / Space-left rows, the "X of Y used" + "Z free"
  quota lines, Breakdown header, the Attachments bucket label, the
  empty state, and all three low-storage **suggestion** sentences
  (with `{percent}` / `{size}` placeholders). Refactored the two
  context-free getters (`_entries`, `_suggestions`) into methods that
  take the resolved `l10n` / labels.
- **`error_state.dart`**: the Retry button (→ `commonRetry`).
- **`install_banner.dart`**: both copy variants (at-risk data-durability
  warning vs. the install tip) + "Got it".
- **`onboarding_tour.dart`**: the Close / Skip / Back / Next / Done
  chrome (reusing the existing `common*` keys).
- **`whats_new_overlay.dart`**: the "What's new in {appTitle}" title +
  Skip / Got it.

ARB: +~20 keys (`storage*`, `installBanner*`, `whatsNewTitle`,
`commonGotIt`), regenerated `AppLocalizations`.

The per-app What's-New / onboarding **content** registries
(`lib/core/whats_new.dart`, the tour steps) stay English for now — only
the shared chrome around them is localized. Log output + terminal I/O
stay English by design (AGENTS.md §1.8).
