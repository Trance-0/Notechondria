# 0.1.184 - Casdoor avatar mirroring (CORS root cause) + editor sidebar scope

## Avatar rendering — the real root cause

Live-debugged with the owner's API credentials:
`auth.trance-0.com` serves avatar files **without any CORS headers**,
while our media CDN (`cdn.trance-0.com`) sends
`access-control-allow-origin` correctly. Flutter web's renderer refuses
to draw cross-origin images without CORS — so every avatar pointing at
Casdoor could never render, regardless of frontend fallback chains.

**Fix (as specified by the owner): store the avatar into our storage at
authentication.**
- `Creator.avatar_mirrored_from` (migration 0036) records the source URL
  of the last mirror.
- `creators.utils.mirror_remote_avatar(creator)` downloads the Casdoor
  avatar (8 s timeout, image content-types only, 8 MB cap) into
  `Creator.image` (→ R2). Idempotent per avatar change; best-effort so a
  slow IdP never blocks login. Called from the Casdoor claims sync on
  every login.
- Payloads (`auth_payload`, settings serializer,
  `creator_summary_payload`): `image_url` — the *effective* avatar — now
  points at the mirrored copy when fresh (CORS-safe); `avatar_url` stays
  the raw Casdoor URL for reference/fallback.
- Frontend bylines (portal + editor) flipped to `image_url` first with
  `avatar_url` as fallback.
- Note: existing accounts heal on their **next Casdoor login** (that's
  when the mirror runs).

## Editor sidebar — only the user's own workspace

The course-list endpoint returns the whole public catalog, and the
editor sidebar listed all of it — so brand-new accounts saw other
people's projects with no subscription involved. The sidebar now shows
only local courses plus cloud courses that are **owned or actively
subscribed** (`is_owned` / `is_subscribed`), so a new user sees exactly
the Inbox folder. There was no auto-subscription anywhere (subscribe is
an explicit POST only) — the catalog listing just made it look that way.
Public-course discovery stays in the Course view.

## Verification

- `AvatarMirrorTests`: mirror stores bytes + records source, idempotent
  per URL (single network call), rejects non-image content, payload
  prefers the mirrored copy, and falls back to the Casdoor URL when no
  mirror exists. Django CI is the gate.
- Live CORS probe transcripts in this doc's rationale (Casdoor: no CORS;
  CDN: proper CORS).
