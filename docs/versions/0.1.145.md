# 0.1.145 - MCP Phase 1: backend API gap audit + docs/server/mcp.md fix

## User request

Continue through `docs/TODO.md`. MCP migration **Phase 1**: confirm
`/api/v1/` covers every MCP tool operation (note versions/sessions,
heatmap, activity-week, calendar feeds); add any missing endpoints. Fix
the stale `ApiKey nch_live_…` auth-header example in
`docs/server/mcp.md` (real header is `Bearer ntc_…`).

## Audit result — no gaps

Mapped all **41** tools in `backend/mcp/tools.py` against the routes in
`backend/notechondria/api_urls.py`. Every tool operation has a REST
equivalent, including the ones the TODO flagged:

- note versions → `notes/<id>/history/`, `…/snapshot/`,
  `…/restore/<version_id>/`
- note sessions → `note-sessions/`, `note-sessions/<id>/`
- heatmap → `heatmap/`
- activity-week → `activity/week/`
- calendar feeds → `calendar-feeds/`, `calendar-feeds/<id>/`
- course unsubscribe → `DELETE courses/<id>/subscribe/`
  (`CourseSubscribeApiView` handles both `post` and `delete`)

So **no new endpoints were needed** — the standalone CLI (plain REST +
the same `ntc_` key) can reach everything the in-backend MCP server can.

- **Test count**: 39 → **51** (verified: `mcp/tests.py` runs 51 tests).
- Added the **MCP⇄CLI parity rule** (every tool lands in both
  `backend/mcp/tools.py` and `cli/notechondria_mcp/tools.py`).
