# 0.1.157 - Portal i18n: settings menu + subpage titles

## Context

Finishing the portal settings chrome (TODO i18n Phase 3). The portal
screens were localized across 0.1.154–0.1.156; this round does the
settings **navigation chrome**.

## What changed (en + zh)

- **Settings menu tiles** (`settings.dart` + `settings_build.dart`):
  Portal preferences, View tutorial, Backend settings, Local data,
  Recycle bin (the main menu) and Personal information, Sign in &
  security, API settings, Connected accounts (the account section) —
  titles + subtitles.
- **Subpage app-bar titles** (`settings_pages.dart`): all seven
  (Personal information, Sign in & security, API settings, Connected
  accounts, Portal preferences, Backend settings, Local data).
- **Portal preferences rows**: Default editor mode / Theme preset /
  Theme mode + the immediate-save caption.

Reused the editor's existing `settings*` keys (from 0.1.140) heavily;
added only a few portal-specific ones (`settingsPortalPreferences`,
`settingsConnectedAccounts`, and the personal-info / security / API
subtitles). ARB: +7 keys.

## Verification

- `flutter analyze` — 0 errors (shared + portal).
- `flutter test` — portal smoke passes.
- `flutter build web` — portal builds.

## Scope / follow-up (last i18n items)

The portal settings **navigation** is localized; the deeper subpage
**body** strings remain English: the personal-info form fields
(Username / Motto / Social link / Change avatar), the API-key section
(`settings_sections.dart` — copy-key instructions), the
backend/offline-mode + download/restore local-data captions, the
recycle-bin dialog, and the Casdoor connected-accounts copy. Plus the
shared `mcp_skill_section.dart`. These are the final i18n cleanup items
(tracked in `docs/TODO.md`).
