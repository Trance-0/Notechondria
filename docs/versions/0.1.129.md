# 0.1.129 - per-app icons, in-app install nudge, legacy storage cleanup

## User request

Authorize the `.gitignore` shared-lib fix (done in 0.1.128) and keep
working down `docs/TODO.md`. This round closes the remaining
"Cross-platform web shell" items except the browser-driver regression
test.

## What changed

### Per-app web icons (cross_platform_plan F3 remainder)

- Replaced the stock Flutter icon set in all three apps with distinct
  per-app glyph icons (generated, committed as PNGs):
  - editor — teal `#0F766E`, "E"
  - planner — indigo `#4338CA`, "P"
  - portal — amber `#B45309`, "N" (Notechondria hub; avoids the P
    collision with planner)
- Each app's `web/icons/Icon-{192,512}.png`,
  `Icon-maskable-{192,512}.png`, and `web/favicon.png` regenerated;
  maskable variants are full-bleed with the glyph kept in the central
  safe zone, regular variants are rounded tiles with padding.
- `web/manifest.json` `theme_color` / `background_color` updated from
  the old Flutter blue `#0175C2` to each app's icon hue so the install
  chrome and splash match.

### In-app install hint + data-durability notice

- New shared `maybeShowInstallBanner` (`install_banner.dart`) shows a
  one-time, dismissible `MaterialBanner` nudging mobile-web visitors to
  Add to Home Screen — the only durable-storage path on iOS (Safari
  ITP evicts a plain bookmark's storage after ~7 days idle; installs
  are exempt). Copy adapts: a signed-out user with local-only drafts
  gets a data-durability warning; everyone else gets a gentle install
  tip.
- New conditional-import probe `web_install_env.dart` /
  `web_install_env_web.dart` exposes `isMobileWebBrowser()` — true
  only on a phone/tablet user agent that is NOT an installed PWA
  (`display-mode: standalone` or iOS `navigator.standalone`). No-op
  on native, desktop, installed PWAs, and `flutter test`.
- Wired into all three apps post-boot (after the What's-New trigger in
  `initial_data.dart`), gated by a persisted `install_hint_dismissed`
  flag in local stats.

### Legacy storage-key cleanup (Settings > Developer)

- `_LocalAppStore.clearLegacyKeys()` (editor) removes the unprefixed
  pre-0.1.127 keys (`notechondria.local_*`, `notechondria.session`,
  and the bare `oauth_*` handoff keys) the 0.1.127 namespacing
  migration deliberately leaves behind (it copies, never moves, so
  each app can migrate independently). Deletes only the exact legacy
  keys; the `notechondria.<app>.*` namespaced keys are untouched.
- Surfaced as a "Clear legacy shared storage" action in the editor's
  Developer settings subpage (`_clearLegacySharedStorage`
  maintenance action + `onClearLegacyStorage` callback plumbed through
  the settings widget). The keys are global to the browser origin, so
  the editor's action clears them for all three apps at once.

### What's-New + docs

- Added a 0.1.129 "Add to your Home Screen" `FeatureUpdate` card to
  each app's `lib/core/whats_new.dart` registry (standing convention).
- `docs/TODO.md`: collapsed the completed Cross-platform web shell
  items; only the browser-driver storage-isolation regression test
  remains (no driver toolchain in this environment).
