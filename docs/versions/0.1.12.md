# Notechondria

Version: 0.1.12
Build Date: 2026-04-08T00:00

## What's Changed

### Cloudflare R2 static/media storage

- [x] Rewired backend to use Cloudflare R2 (S3-compatible) for static and media files when `CLOUDFLARE_R2_BUCKET_NAME` is set. Falls back to local filesystem + nginx when unset (Docker Compose).
- [x] Added `django-storages[s3]` and `boto3` to `requirements.txt` and `requirements-render.txt`.
- [x] Added conditional `STORAGES` configuration in `settings.py` with credential validation.
- [x] Added Cloudflare R2 environment variables to `sample.render.env`.
- [x] Added "Cloudflare R2 storage" setup section to `docs/deployment/render_free_tier.md`.

### Splash animation improvements

- [x] Slowed Krebs cycle animation from 4s to 8s duration across all three apps.
- [x] Removed "Citric Acid Cycle" center title label.
- [x] Replaced English chemical names with structural formula representations drawn via Canvas (e.g. `HOOC-CH2-C(OH)-CH2-COOH` for Citrate, double-bond notation for Fumarate, `S-CoA` groups for Succinyl-CoA).
- [x] Changed Acetyl-CoA label to structural formula `CH3-CO-S-CoA`.

### OAuth callback redirect

- [x] Added `oauth_callback` view in `api_views.py` that handles GET redirects from Google/GitHub OAuth providers.
- [x] On error: renders a styled static HTML page with failure icon and message.
- [x] On success: redirects to the frontend SPA with `code` and `state` query parameters.
- [x] Added `/auth/google/callback` and `/auth/github/callback` URL routes in `urls.py`.

### OAuth bind feedback

- [x] Added SnackBar feedback in all three app shells (`editor`, `planner`, `portal`) for social account bind success/failure after OAuth callback.

### Lazy loading for note list

- [x] Replaced "Load more" button in the learner note list with scroll-based lazy loading.
- [x] Added `ScrollController` with listener that triggers load when scrolled within 200px of the bottom.
- [x] Shows `CircularProgressIndicator` at list bottom while loading more notes.
