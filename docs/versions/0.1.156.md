# 0.1.156 - Portal i18n: block editor + activity/calendar (Phase 3 complete)

## Context

Finishing TODO i18n **Phase 3 (portal)**. 0.1.154 did front + course,
0.1.155 the learner feed + note dialog; this round localizes the
block-note editor and the activity/calendar surfaces — the last
English-heavy portal screens.

## What changed (en + zh)

- **`learner_note_editor.dart`** (block note editor): the block-type
  menu (Paragraph / Heading / List / Code / Quote / Link / Image /
  Delete block), the formatting toolbar (Bold / Italic / Strike / Add
  paragraph / Add list / Add code), the block-args + content hints, the
  Title / "Write your note…" hints, the editor-mode dropdown
  (Plain / Preview / Blocks + label), and the `_SaveStatus` indicator
  (Saving… / Not saved / Saved {time}).
- **`activity.dart`**: the sign-in prompt, the empty-week / no-deadline
  / no-urgent states, the week-range "This week" label, the
  prev/next-week tooltips, the FAB menu (Create event / Import iCal /
  Subscribe calendar) + its hint.
- **`activity_week.dart`**: the "Week calendar" label + nav tooltips,
  the **New event** dialog (Event title, Description, Weight {n},
  Difficulty, Cancel, Saving…/Create), and the **Subscribe to calendar**
  dialog (Title, iCal URL, Cancel, Subscribe + the default
  "Subscribed calendar" name).

ARB: +~45 keys (`editor*`, `activity*`, plus `commonLoading`).
`editor*` keys are named generically so the editor app's block editor
can share them later. Reused `common*` / `note*` / `course*` keys where
they matched.

### Left English by design

Data-default values (`onCreateNote` title), `XTypeGroup` file-picker
labels (OS dialog chrome), the short technical block-arg labels
("Language" / "URL"), and log/diagnostic lines (AGENTS.md §1.8).
