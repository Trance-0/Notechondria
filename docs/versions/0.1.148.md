## What changed (en + zh)

The full auth surface (shared by all three apps) now reads from
`AppLocalizations`:

- **`auth_dialogs.dart`**
  - `AuthHub`: the "Account" header, both SSO description variants
    (Casdoor-primary vs. fallback), "Continue with Casdoor SSO", "No
    account? Sign up via Casdoor", the email/password expander
    (Hide / Use…), the legacy Login button, and the forgot-password
    note.
  - `EmailPasswordDialog`: the host subtitle ("Signing in to {host}"),
    the Email / Password field labels, the Cancel/Close + submit
    buttons, the "Working…" state, and the three phased-status lines
    ("Sending request to backend" / "Waiting for backend response" /
    "Applying response").
- **`casdoor_link_challenge_dialog.dart`**: the title, "Casdoor signed
  you in as:", the choose-pane intro + both option buttons and their
  descriptions, the bind/create pane descriptions + field labels, the
  Back/Cancel/Bind/Create actions, and the three form-validation error
  messages.

ARB: +~35 keys (`auth*`, `link*`), regenerated `AppLocalizations`.

### Fragility fixed

`EmailPasswordDialog` decided whether to fire the browser "Save
password?" prompt by comparing `widget.title == 'Login'` — which would
break the moment the title became a localized string. Replaced it with
an explicit `finishAutofillOnSuccess` bool (the login caller sets it
true). The only caller is the AuthHub login dialog.
