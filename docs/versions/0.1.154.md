# 0.1.154 - Portal: editable API URL (signed-out) + front/course i18n

## User reports

1. **Bug:** the portal app gave no way to edit the backend API URL — a
   signed-out user couldn't point the app at a backend, so it couldn't
   function.
2. Portal translation is incomplete — continue translating (TODO i18n
   Phase 3).

## Fix: API base URL editable while signed out

The editable API-URL field + key-rotate lived only on portal's
`_ApiSettingsPage`, which is reached from the **signed-in** account
section (`settings_build.dart`). A signed-out user only saw
Preferences / Backend / Local data / Recycle bin, and the Backend page
showed the URL **read-only** with "edit it on the API settings page" —
unreachable without signing in. Catch-22: you couldn't fix a wrong
backend URL without logging in, and couldn't log in against the wrong
URL.

Replaced the read-only "Backend endpoint" display in
`_BackendSettingsPage` (always reachable) with the **editable API base
URL field** — the same widget `_ApiSettingsPage` uses (controller
`p._apiBaseController`, locked while authenticated, Enter to apply via
`_autoSavePreferences`). This matches how the editor/planner already
expose it, so portal can now be repointed at a backend before login.
The signed-in `_ApiSettingsPage` (URL + MCP key) is unchanged.

## i18n: portal front page + course browser (en + zh)

Localized the two highest-visibility portal-distinctive screens:

- **`front.dart`**: hero greeting (`Welcome back, {name}` / guest), both
  intro blurbs, the "Recent public courses" / "Activity heatmap" /
  "Recent public notes" section headers, the heatmap legend, and the
  "No public courses yet." empty state.
- **`course.dart`**: the create-local-course dialog, Create-local /
  Sync-local-data buttons, the module view (Back to {course},
  Objectives, Assignments, Module discussion + empty state), the course
  view (Subscribe/Unsubscribe, Modules header, {count} note(s), Course
  discussion + empty state), the course-list dropdown label, and the
  shared discussion board's Load-more / Untitled-note.

ARB: +~30 keys (`front*`, `course*`), regenerated `AppLocalizations`.
Reused existing `common*` / `category*` / `note*` keys where they
matched.
