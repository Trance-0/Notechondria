# 0.1.139 - splash particle density scales with screen size

## User request

The reaction-simulator splash was dense on small screens and sparse on
large ones. Make the particle count scale with screen size, calibrated
to the current count (128) for a 1920×1080 screen.

## What changed

The particle target is now derived from the viewport **area** instead
of a fixed 128, so on-screen density is constant across screen sizes.

- `notechondria_shared/.../reaction_defs.dart`: replaced
  `ReactionSimOptions.maxParticles = 128` with a calibration set —
  `referenceParticles = 128` at `referenceArea = 1920×1080`,
  `minParticles = 24`, `maxParticlesCap = 320`.
- `reaction_simulator.dart`: new `ReactionSimulator.targetParticles`
  getter = `round(width × height ÷ (referenceArea ÷ referenceParticles))`
  clamped to `minParticles..maxParticlesCap` (falls back to 128 before
  the first `setSize`). `populationTick()` now targets this instead of
  the old constant. The view already calls `setSize` with the widget
  constraints, so the field auto-rescales when the window resizes.

Calibration points: 1920×1080 → 128; 960×1080 → ~64; a 360×640 phone
clamps up to 24 (not left empty); an 8K monitor caps at 320 (not
overwhelming).

## Verification

- `notechondria_shared` `reaction_simulator_test.dart`: updated the
  population test to the 1920×1080 reference (→128 target) and added a
  scaling/clamp test (area-proportional, min/max bounds). All pass.
- `flutter analyze` — 0 errors in `notechondria_shared`.
