# 0.1.138 - standalone MCP CLI skeleton (cli/) — Phase 2

## User request

Keep both MCP and the CLI (separate endpoints, shared API auth; one API
key per user). CLI decisions: use a `cli/` directory in this repo
(treat as an independent program, may move to its own repo later);
Python; keep `/mcp/` until further notice; agent-oriented development —
every new function lands in both the MCP and the CLI implementations.

## What changed

### New `cli/` program (Phase 2 of the migration)

A runnable standalone MCP server in [`cli/`](../../cli/), independent of
`backend/` (own `pyproject.toml`, no `backend/` imports):

- `notechondria_mcp/config.py` — resolves the backend URL + `ntc_` API
  key from env (`NOTECHONDRIA_API_URL` / `NOTECHONDRIA_API_KEY`) or
  `~/.notechondria/config.json`; normalizes the `/api/v1` suffix; never
  echoes the key.
- `notechondria_mcp/client.py` — a `requests`-based client sending
  `Authorization: Bearer ntc_<key>` on every call (the same auth the
  in-backend `/mcp/` uses — shared credential, one key per user).
- `notechondria_mcp/tools.py` — a tool registry mirroring
  `backend/mcp/tools.py` names + input schemas, each mapping to a
  `/api/v1/` request. Representative subset: `get_profile`,
  notes CRUD (`list_notes`/`get_note`/`create_note`/`update_note`/
  `delete_note`), `list_courses`/`get_course`/`create_course`,
  `list_events`/`create_event`.
- `notechondria_mcp/server.py` — a stdio JSON-RPC 2.0 MCP loop
  (`initialize` fetching the user's `mcp_skill_md` as `instructions`,
  `tools/list`, `tools/call`, `ping`, notifications), mirroring
  `backend/mcp/protocol.py`. Transport is hand-rolled (no external MCP
  SDK dependency yet) so the skeleton is self-contained and testable;
  it can adopt the official Python `mcp` SDK later without touching the
  tool layer.
- `notechondria_mcp/__main__.py` — `notechondria-mcp` entry point with
  `check` (config + connectivity) and the default `serve` (stdio).
- `cli/README.md` — install, config, agent-host wiring, the parity rule.
- `cli/tests/test_server.py` — 10 unit tests (no network, no SDK):
  registry shape, dispatch, initialize instructions, error codes.

No backend change was needed: `ntc_` keys already authenticate every
`/api/v1/` endpoint (`ApiKeyAuthentication` is in
`DEFAULT_AUTHENTICATION_CLASSES`), and `mcp_skill_md` is already served
by `GET /api/v1/settings/`.
