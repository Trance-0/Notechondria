## What changed

### Splash: reaction simulator (Dart port)

- New `notechondria_shared/lib/src/reaction_simulator/`
  (`reaction_defs.dart`, `reaction_simulator.dart`,
  `reaction_view.dart`): a Dart port of the upstream `particle.js` /
  `reaction_manager.js` / `simulator.js` / `renderer.js` /
  `pictograms.js` with the TCA preset and CPK palette. TCA molecules
  drift on a toroidal world, exchange velocity on contact, fire
  bimolecular + ripening reactions with pictogram badges, and the
  population manager holds the field near the hardcoded
  128-particle target with spawn kinetic energy ~ N(250000, 60000)
  (`ReactionSimOptions`). A Dart port was chosen over a JS embedding
  because the splash also ships in desktop/mobile native builds where
  a webview embedding would not run.
- Intentionally dropped from the port (animation-only splash, per the
  owner's "fine to remove the config" note): presets/themes/colormap
  config, HSV shifts, particle tracking + hit-testing, and labelled
  reaction boxes.
- `SplashScreen` now renders `ReactionSimulatorView` as its backdrop;
  the hand-drawn `splash_painter.dart` Krebs-cycle painter (840
  lines) is deleted. One porting bug was caught by the new tests:
  upstream JS mutates the particle array during `for..of` in
  `_ripen`, which Dart iterators reject — the port iterates a
  snapshot instead.

### OAuth callback app routing (TODO item, cross_platform_plan F5)

- `backend/notechondria/api_views.py` `oauth_callback` now maps a
  `state` suffix (`_editor` / `_planner` / `_portal`, mirroring the
  `_bind` convention) to the matching frontend path for its same-tab
  fallback redirect; legacy states keep the editor default.
- `GithubSyncExperimentalCard` gained an `appId` parameter and
  appends `state=app_<appId>` to the GitHub App install URL (GitHub
  round-trips `state` to the callback); all five construction sites
  across the three apps pass their app id.

### Docs + housekeeping

- `.gitignore`: owner-authorized negations
  `!frontend/notechondria_shared/lib/**` and `test/**` — the
  Python-style `lib/` ignore was silently hiding new shared-package

- `docs/readme.md`: new "Installing on a phone (web channel)" section
  (Add-to-Home-Screen guidance; bookmark vs install storage-eviction
  difference). The in-app hint card + durability notice remain in
  `docs/TODO.md`.
- `docs/client/notechondria_shared.md`: splash row updated for the
  simulator port; `docs/TODO.md`: OAuth-routing item completed and
  removed, install-guidance item narrowed to the in-app remainder.
