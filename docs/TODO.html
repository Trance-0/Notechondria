  • Attachment CDN rework (user-reported). Current behavior writes base64 data URIs inline and queues raw bytes in metadata_json['queued_attachments'] as base64. Spec:

    • Migration shim. Existing drafts carry base64 in metadata_json['queued_attachments']. On load, migrate each such entry to the local file store one-time and rewrite the body references.
