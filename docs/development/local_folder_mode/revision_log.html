Resolved differently from the review's literal wording:

  • M4 asked that GET handlers skip paths named by a pending journal. Here GET handlers take the lock in shared mode, so they never see an operation in progress, and a crash-left journal is rolled forward before the read. Skipping applies only when that roll-forward fails (6.2 R3). This is stricter than skipping and needs no per-path filter in the common case.
  • M3 offered a shorter lock wait or running local requests outside the budget. The design does both: a one-condition change in send() keeps local requests out of the budget, and the 5 s lock wait and 8 s read deadline keep the bound below 10 s even without that change (2.7, 2.9). (Revision 2 withdrew the "even without that change" part; see N8.)
  • M6 suggested dropping or remapping server IDs on adopt. Adopt keeps them, because a clone holds one account's IDs, which are already unique per kind; counters are raised above them, and any real collision falls under the duplicate rule (3.7).

Resolved differently from the review's literal wording:

  • N1 offered a pending mode or a synchronous decision. The design uses both parts: the mode is decided synchronously, and a separate folder state, opening, holds requests while the folder is opened. Holding (instead of answering 503) is what lets a cold portal deep link render the folder note.
  • N8 offered a write deadline or dropping the claim. The design adds the deadline and also narrows the claim, because a started write cannot be cut off safely.
  • N11 offered an exemption or coalescing. The design uses separate pools, which keeps every automatic snapshot up to its own cap and needs no timing rule.
  • N15 suggested comparing the body with the pre-op sidecar. The record stores the expected size and lastModified instead, because a crash after step 3's sidecar writes leaves the new sidecar on disk.
  • N2 named Zone.current; the design binds the lock callback in the zone of the request that asked for the lock, which is Zone.current at the call, and keeps the controller's captured zone for void listeners only.
